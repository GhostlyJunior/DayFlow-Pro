# DayFlow Pro

DayFlow Pro is a student organization web app designed to help students manage their daily routine in a structured, motivating, and interactive way. The app helps students organize their responsibilities, track their academic progress, and stay focused during the day.

## Main Features

- User login system
- Personal dashboard
- Daily goals and task tracking
- XP points and streak system
- Weekly study hours tracking
- Pomodoro focus timer
- Notes section
- Reward store
- Firebase cloud saving
- Image evidence before completing tasks

## How It Works

The student can start the day and move through different sections such as school schedule, room organization, homework, scholarship study, programming practice, and final evidence. Each task is designed to help the student stay organized and complete real responsibilities.

One of the most important features is the image evidence system. Before marking a task as completed, the student must upload proof, such as a photo of completed homework, study progress, or an organized workspace. This makes the progress more honest and realistic.

## Purpose

The goal of DayFlow Pro is to help students build discipline, stay motivated, and improve their academic habits. Instead of being only a simple to-do list, the app turns productivity into a more interactive experience using XP, streaks, timers, and rewards.

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase

## Project Status

DayFlow Pro is currently a functional student productivity web app with multiple organization tools, progress tracking features, and a motivational reward system.
